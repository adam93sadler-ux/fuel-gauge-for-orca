# Security

Report credential exposure privately to the repository maintainer through GitHub private vulnerability reporting if enabled, or request a private contact channel without disclosing details. Revoke exposed credentials with the provider.

The trusted worker reads existing local credentials. Claude, Codex and DeepSeek requests send authorization only to api.anthropic.com, chatgpt.com and api.deepseek.com respectively, with redirects disabled. Antigravity uses the local agy CLI. The snapshot contains usage windows, balances and status. Keep snapshots, login files, transcripts and real account screenshots out of issues and pull requests.
